# Deployment & Configuration Guide

VertiWiki is 100% static and requires **no backend server, no runtime database, and no server-side compilation**.

---

## 🛠️ Required Files in Your Root Folder

When serving or publishing your wiki, ensure the following core files exist in the same directory:

| File | Purpose |
| :--- | :--- |
| `index.html` (or `vertiwiki.html`) | The single-file standalone VertiWiki engine generated by `npm run build`. |
| `config.json` | Global site configuration (title, theme, features). |
| `navigation.md` | Sidebar navigation hierarchy and links. |
| `index.md` | Home landing page of your wiki. |
| `404.md` | Graceful fallback page when a requested document is not found. |

## 📊 Analytics & Tracking Providers

VertiWiki includes out-of-the-box support for the leading analytics platforms. Simply provide your ID/Token in `config.json` without modifying any code:

| Provider | Config Key in `config.json` | Description |
| :--- | :--- | :--- |
| **Google Analytics 4** | `"googleAnalyticsId": "G-XXXXXXXXXX"` | Official GA4 measurement with automatic SPA hash route tracking. |
| **Google Tag Manager** | `"gtmId": "GTM-YYYYYY"` | Pushes `vertiwiki_pageview` events to `dataLayer`. |
| **Plausible Analytics** | `"plausibleDomain": "domain.com"` | Lightweight, privacy-first, GDPR-compliant analytics. |
| **Cloudflare Web Analytics** | `"cloudflareToken": "token"` | Zero-cookie, privacy-first web traffic measurement. |
| **Umami Analytics** | `"umamiWebsiteId": "uuid"` | Self-hosted or Cloud open-source analytics. |
| **Matomo Analytics** | `"matomoUrl": "...", "matomoSiteId": "1"` | Enterprise self-hosted analytics engine. |

## 🚀 Deployment Platforms

### 1. GitHub Pages
1. Push your `.md` files, `config.json`, `navigation.md`, and `dist/index.html` to your GitHub repository.
2. In Repository Settings &rarr; **Pages**, choose the `main` branch (or `/docs` folder).
3. Your wiki is immediately live with HTTPS!

### 2. Netlify / Cloudflare Pages / Vercel
* **Build Command**: `npm run build`
* **Output Directory**: `dist`
* Or simply drag-and-drop the directory containing `index.html` and your `.md` files!

### 3. Local Offline Use / USB Flash Drive
* Because VertiWiki runs completely client-side in the browser, you can copy your folder to a USB drive or local shared network folder.
* Open with a simple static server (e.g. `npx serve .` or `python3 -m http.server`).
