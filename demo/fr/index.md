# Bienvenue sur VertiWiki ⚡

**VertiWiki** est un moteur de wiki et de documentation Markdown 100% statique, distribué en un **seul fichier autonome**, avec **zéro backend** et zéro étape de compilation côté serveur.

> [!NOTE]
> Cette page est une démonstration du support **Multi-Langues (i18n)** de VertiWiki. Vous pouvez changer de langue à tout moment via le sélecteur dans l'en-tête.

---

## Points Forts

* **Zéro Backend** : Déployable sur GitHub Pages, Cloudflare Pages, Netlify ou n'importe quel hébergement statique.
* **Fichier Unique Autonome** : L'ensemble de la logique, des feuilles de style, de KaTeX et de Prism.js est intégré dans `vertiwiki.html`.
* **Support Multi-Langues Natif** : Structure en miroir (`fr/`, `ro/`, etc.) avec indexation MiniSearch isolée par langue.
* **Changement de Thème GPU** : Commutation de thème en moins d'une milliseconde sans rechargement de page.

---

## Démarrage Rapide

1. Téléchargez le fichier `vertiwiki.html`.
2. Placez vos fichiers Markdown (`index.md`, `navigation.md`) dans le même répertoire.
3. Pour ajouter une langue, créez simplement un sous-dossier (par exemple `fr/`) et déclarez-le dans `config.json`.
